# LocalTube

Локальный видеосервис для скачанных с YouTube видео. Выглядит и работает как YouTube, но всё лежит на вашем диске и не зависит от интернета.

Скачиваете видео через yt-dlp, а LocalTube показывает их каталогом с превью, страницами каналов, вертикальной лентой Shorts, избранным и историей просмотров.

## Что умеет

### Каталог и навигация

Главная страница показывает сетку видео, отдельную полку Shorts и раздел «Мои видео». В боковом меню — каналы вашей библиотеки, избранное, история, очередь загрузок и список скрытых каналов.

Страница канала: баннер, аватар, число подписчиков, вкладки «Главная / Видео / Shorts / Плейлисты / О канале», сортировка по дате. Есть кнопка «Скачать остальные видео» — она сверяет локальную библиотеку с каналом на YouTube и предлагает недостающее.

Поиск работает по названию и автору.

### Плеер

Собственный плеер вместо стандартного браузерного:

- Превью кадров при наведении на полосу прогресса (storyboard с YouTube)
- Возобновление с места, где остановились
- Театральный режим и мини-плеер, который продолжает играть при переходе на другие страницы
- Скорость 0.5x / 1x / 1.5x / 2x
- Двойной клик по левой или правой части видео — перемотка на 10 секунд
- Эквалайзер на 9 полос с пресетами и усилением басов
- Субтитры: скачивание с YouTube, загрузка своих файлов VTT/SRT
- Извлечение звука в MP3

Горячие клавиши:

| Клавиша | Действие |
|---|---|
| `Space`, `K` | Пауза / воспроизведение |
| `F` | Полный экран |
| `T` | Театральный режим |
| `I`, `P` | Мини-плеер |
| `M` | Выключить звук |
| `←` / `→` | Назад / вперёд на 5 секунд |
| `↑` / `↓` | Громкость |

### Shorts

Вертикальные видео определяются автоматически: по соотношению сторон, длительности и хештегам. Лента прокручивается как в мобильном YouTube — с прилипанием к границам кадра, автозапуском видео в фокусе и общей громкостью на всю ленту.

### Очередь загрузок

- Три уровня приоритета: высокий, обычный, низкий
- Пауза очереди (текущая загрузка при этом не обрывается)
- Отмена загрузки с удалением недокачанного файла
- Повтор упавших задач, в том числе всех сразу
- Прогресс с текущей скоростью и оценкой времени
- Задачи переживают перезапуск сервера: прерванные возвращаются в ожидание

### Личные данные

Избранное, история просмотров и скрытые каналы хранятся на сервере, а не в браузере. Это значит, что они не теряются при чистке кэша и доступны со всех устройств в вашей сети.

Скрытие канала убирает его видео из всех подборок — главной, поиска, рекомендаций и ленты Shorts. Сама страница канала при этом продолжает работать.

Очистить любой из разделов можно в настройках.

### Конвертация видео

Через ffmpeg, прямо из интерфейса: 2160p, 1440p, 1080p, 720p, 480p, 144p, а также «Улучшайзер» (повышение резкости) и «Шакализатор» (нарочитое ухудшение до 144p).

### Оформление

Три темы: тёмная, светлая и Frutiger Aero — со стеклянными панелями, собственным шрифтом и фоновыми обоями, которые плавно меняются каждые 30 секунд.

Интерфейс адаптирован под телефоны.

## Требования

Обязательное:

- **Python 3.8+** (проверено на 3.11–3.13)
- **FFmpeg** — склейка видео и аудио, конвертация, извлечение MP3

Опциональное:

- **Deno** — для `yt-dlp-ejs`, помогает обходить JS-проверки YouTube
- **bgutil-pot** — сервер выдачи PO Token, нужен части клиентов YouTube (см. [Cookies и доступ к YouTube](#cookies-и-доступ-к-youtube))
- **Node.js** — только для браузерных тестов

## Установка

```bash
git clone https://github.com/kiramorano/LocalTube.git
cd LocalTube
pip install -r requirements.txt
```

### FFmpeg

**Windows.** Скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html), распакуйте в `C:\ffmpeg` и добавьте `C:\ffmpeg\bin` в переменную PATH.

**Linux (Ubuntu/Debian):**

```bash
sudo apt install ffmpeg -y
```

**macOS:**

```bash
brew install ffmpeg
```

### Проверка окружения

В проекте есть помощник, который проверяет всё сразу — Python, пакеты, ffmpeg, deno, папки, плагины:

```bash
python worker.py check     # проверить
python worker.py auto      # проверить и починить что можно
```

## Запуск

```bash
python app.py
```

Откройте `http://127.0.0.1:5000`.

Сервер слушает все сетевые интерфейсы, поэтому с телефона в той же сети он доступен по адресу вида `http://192.168.1.50:5000`. Обратите внимание на раздел [Ограничения](#ограничения-и-известные-проблемы): аутентификации нет.

## Как устроены данные

Всё хранится обычными файлами и папками. Никакой базы данных, поэтому библиотеку можно переносить копированием и править вручную.

```
videos/
  <Автор>/
    <video_id>/              обычное видео
      video.mp4
      info.json              метаданные от yt-dlp
      thumbnail.jpg
    <video_id> #shorts/      вертикальное видео
avas/
  <Автор>.jpg                аватар канала
  banners/<Автор>.jpg        шапка канала
  meta/<Автор>.json          описание, подписчики, статус синхронизации
uservideos/
  <Пользователь>/<id>/       видео, загруженные вручную
playlists/
  <Название>/playlist.json
subtitles/
  <youtube|user>/<id>/<lang>.vtt
```

Служебные файлы в корне:

| Файл | Что внутри |
|---|---|
| `config.json` | пути к каталогам, настройки доступа к YouTube |
| `userdata.json` | избранное, история, скрытые каналы |
| `queue.json` | очередь загрузок, переживает перезапуск |
| `cookies.txt` | cookies для YouTube |
| `logs.txt` | журнал работы |

Все эти файлы записываются атомарно: сначала во временный файл, затем подменой. Рядом сохраняется копия предыдущей версии с расширением `.bak` — если основной файл повредится, данные читаются из неё. Сбой записи не приводит к потере уже сохранённого.

Библиотека сканируется с кэшированием: папка перечитывается только если изменилось время правки или размер файлов. На библиотеке из 500 видео это ускоряет поиск примерно в четыре раза.

## Настройка

Основное настраивается на странице `/settings`:

- **Профиль и оформление** — отображаемое имя, аватар, тема
- **Загрузка с YouTube** — клиент YouTube, режим PO Token, импорт cookies
- **Мои данные** — сводка и очистка избранного, истории, скрытых каналов
- **Обслуживание** — проверка плагинов и диагностика

Пути к каталогам меняются правкой `config.json`:

```json
{
  "video_dir": "videos",
  "avatars_dir": "avas",
  "thumbnails_dir": "thumbnails",
  "playlists_dir": "playlists",
  "subtitles_dir": "subtitles"
}
```

Порт (5000) и хост заданы в коде, в конце `app.py`.

## Cookies и доступ к YouTube

YouTube всё активнее ограничивает скачивание: требует авторизацию, отдаёт ошибку «Sign in to confirm you're not a bot» или урезанные форматы. Два механизма помогают это обойти.

### Cookies

Файл `cookies.txt` в формате Netscape. Способы получить:

1. Расширение браузера («Get cookies.txt») → экспорт → вставить содержимое в `/settings`
2. Загрузить файл там же
3. Положить `cookies.txt` в корень проекта вручную

**Не публикуйте этот файл.** Он даёт полный доступ к вашему аккаунту YouTube. В `.gitignore` он уже указан.

### PO Token

Часть клиентов YouTube требует Proof-of-Origin Token — подтверждение, что запрос пришёл от настоящего браузера. LocalTube сам его не считает, а обращается к внешнему провайдеру `bgutil`.

Режимы в настройках:

- **Выключено** — подойдёт для клиентов `tv` и `web_safari`
- **bgutil HTTP** — сервер на `127.0.0.1:4416`
- **bgutil CLI** — локальный бинарник `bgutil-pot`

Плагины для yt-dlp создаются автоматически при первом запуске. Управление HTTP-сервером:

```bash
python server.py --start
python server.py --status
python server.py --stop
```

Если скачивание не работает, начните с выбора клиента `tv` плюс cookies — эта комбинация не требует PO Token.

## Android-приложение

В папке `android/` — самостоятельное приложение на Kotlin и Jetpack Compose. **Сервер ему не нужен**: yt-dlp и FFmpeg встроены в APK, видео скачиваются прямо на устройство.

Возможности: каталог с вкладками, поиск, очередь загрузок с выбором качества, плеер на ExoPlayer с субтитрами, лента Shorts, плейлисты, свои видео, импорт cookies, обновление yt-dlp из приложения.

Требования: Android 7.0 и новее.

Готовые APK — во вкладке [Releases](https://github.com/kiramorano/LocalTube/releases): `app-arm64-v8a-release.apk` для современных телефонов, `app-universal-release.apk` универсальный.

Сборка из исходников (нужны JDK 17 и Android SDK 35):

```bash
cd android
./gradlew assembleRelease
```

## Ограничения и известные проблемы

**Нет аутентификации.** Сервер слушает `0.0.0.0:5000`, поэтому любое устройство в сети получает полный доступ, включая удаление видео и импорт cookies. Запускайте только в доверенной домашней сети и не открывайте порт наружу.

**Нет поля для скачивания на главной.** Единственный работающий способ добавить видео — кнопка «Скачать остальные видео» на странице канала. Интерфейс добавления по ссылке в текущей версии отсутствует.

**Выбор качества в плеере не переключает поток.** Меню показывает доступные форматы, но для смены качества нужна серверная конвертация.

**Скачивание зависит от YouTube.** Ограничения меняются, поэтому иногда требуется обновить yt-dlp (`python worker.py update`), сменить клиент или обновить cookies.

**Каталог `thumbnails/` не используется** — превью хранятся рядом с видео.
