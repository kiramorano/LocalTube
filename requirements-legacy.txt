# -*- coding: utf-8 -*-
# Директива кодировки обязательна и стоит первой строкой: pip читает файл
# требований в кодировке системы, а на Python 3.8 под русской Windows это
# cp1251. Без директивы pip падал с UnicodeDecodeError на кириллице в
# комментариях ниже, то есть установить зависимости для Windows 7 было нельзя
# вовсе — ни локально, ни в CI.
#
# Зависимости для сборки под Windows 7 (x64 и x86).
#
# Windows 7 остановилась на Python 3.8: более новые сборки CPython не
# запускаются там вовсе (отсутствуют функции API в kernel32). Отсюда весь список
# версий ниже — это последние выпуски каждого пакета, ещё поддерживающие 3.8.
# Ставить их поверх обычного requirements.txt нельзя: pip выберет свежие версии,
# и полученный exe на «семёрке» не запустится.
#
# Использование:
#   py -3.8 -m pip install -r requirements-legacy.txt

# Последняя версия yt-dlp с поддержкой Python 3.8. Начиная со следующей
# требуется 3.9, а с 2025.10 — уже 3.10.
# ВАЖНО: эта версия не умеет SABR и PO-токены, поэтому загрузка с YouTube может
# обрываться на 13-17 МБ с ошибкой 403. Локальная библиотека, конвертация,
# извлечение MP3 и субтитры работают полностью. Подробности в docs/PLATFORMS.md.
yt-dlp==2024.10.22
# yt-dlp-ejs здесь намеренно отсутствует: пакет требует Python 3.10.

Flask==3.0.3
Werkzeug==3.0.6
Jinja2==3.1.6
requests==2.32.4
Pillow==10.4.0
waitress==3.0.0
segno==1.6.6

# Встроенный Chromium для окна. На Windows 7 WebView2 отсутствует и установить
# его нельзя, поэтому движок укладывается внутрь приложения. Версия 66.1 —
# последняя с колёсами для Windows; внутри есть модуль для Python 3.8, а
# проприетарные кодеки (H.264, AAC) в её libcef.dll включены, без них видео с
# YouTube не проигрывается.
cefpython3==66.1
# pywebview использует cefpython3 как движок; на Windows дополнительно тянет
# pythonnet для доступа к WinForms.
pywebview==4.4.1

# PyInstaller 6.x объявляет поддержку только Windows 8 и новее: собранный им exe
# на Windows 7 не запускается. 5.13.2 — последняя версия, где «семёрка» ещё
# работает.
pyinstaller==5.13.2
