# Тесты LocalTube

## Python (pytest)

```bash
pip install -r requirements-dev.txt
python -m pytest
```

192 проверки: очередь загрузок, отмена и приоритеты задач, диагностика
синхронизации каналов, кэш сканирования библиотеки, пользовательские данные
(избранное, история, скрытые каналы), серверная фильтрация скрытых каналов,
безопасная запись JSON, Jinja-фильтры и целостность шаблонов. Сеть не
используется, реальные `queue.json`, `userdata.json`, `config.json` и
`avas/meta/*.json` не изменяются.

## Браузерные тесты (Playwright)

Нужен запущенный сервер:

```bash
python app.py
```

Затем в отдельном терминале:

```bash
cd tests/browser
npm install
npx playwright install chromium
npm test
```

`npm test` прогоняет все 10 скриптов. Отдельные группы: `npm run queue`,
`npm run channel`, `npm run mobile`, `npm run audit`.

`userdata-verify.cjs` проверяет перенос данных из localStorage на сервер и
доступность избранного с другого устройства. `hidden-channels.cjs` проверяет
серверную фильтрацию скрытых каналов и кнопку на странице канала. Оба
временно очищают разделы пользовательских данных, поэтому запускать их стоит
не на рабочих данных.

Скриншоты складываются в `tests/browser/shots/` и не попадают в git.
Все обращения к YouTube в этих тестах перехватываются, поэтому сеть не нужна.
